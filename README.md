# Gotilo (ગોતીલો) — બસ કહો, ગોતીલો.

> **"Just tell us. We'll find it."**  
> A hyperlocal city application connecting people with daily essentials, local shops, skilled professionals, and emergency doorstep services.

---

## 🌟 Key Features

- 💬 **Conversational City Bot**: Natural speech and text input (English, ગુજરાતી, हिन्दी).
- 🧹 **Everyday Essentials & Services**:
  - Sweeper & Maids, Plumbers, Electricians, AC & Refrigerator Technicians, Locksmiths & Key Makers.
  - Daily Milk (Amul) & Bread, Kirana & Ration, Vegetables & Fruits, 20L Water Jars.
  - Urgent Xerox & Printout, Bike/Car Doorstep Puncture Repair, 24x7 Medicines.
- ⚡ **AI Model Support**: Integrated with Google Gemini Flash API + Built-in offline Hyperlocal NLP engine.
- 📱 **Clean Responsive UI**: Warm off-white minimal design, 5-tab navigation, PWA-ready.

---

## 🚀 Quick Start

Open `index.html` in any modern web browser.
